## 코딩 실습 5문항

### 16. [chapter01] 명령행 인자 출력 프로그램
`main(String[] args)`를 사용하여 프로그램 실행 시 전달된 문자열을 한 줄씩 출력하시오.

조건:
- 인자가 없으면 `입력된 인자가 없습니다.`를 출력할 것
- 인자가 있으면 `args[0]: 값` 형식으로 출력할 것

예시 출력:

```text
args[0]: hello
args[1]: java
```

### 17. [chapter02] 배열 합계와 평균 구하기
정수 배열을 받아 합계와 평균을 출력하는 프로그램을 작성하시오.

조건:
- 배열은 `{90, 85, 95, 100}`으로 시작할 것
- `Arrays.toString()`을 사용해 원본 배열도 함께 출력할 것
- 평균은 소수 둘째 자리까지 출력할 것

예시 출력 형식:

```text
scores: [90, 85, 95, 100]
sum: 370
avg: 92.50
```

### 18. [chapter03~04] RPG 캐릭터 클래스 작성
이름, 직업, 레벨을 가지는 `Character` 클래스를 만들고, 이를 상속하는 `Warrior`와 `Mage` 클래스를 작성하시오.

조건:
- 부모 클래스에 `attack()` 메서드를 만들고 자식 클래스에서 오버라이딩할 것
- `main()`에서 `Character[]` 배열에 `Warrior`, `Mage` 객체를 넣고 반복문으로 `attack()`을 호출할 것
- 각 직업마다 다른 공격 메시지가 출력되어야 함

### 19. [chapter05] 사용자 정의 예외를 이용한 점수 검증
점수가 0 미만 또는 100 초과이면 예외를 발생시키는 프로그램을 작성하시오.

조건:
- `InvalidScoreException` 클래스를 직접 만들 것
- `checkScore(int score)` 메서드에서 검증할 것
- 정상 점수와 비정상 점수를 각각 한 번씩 테스트할 것

예시 상황:
- `85`는 정상
- `120`은 예외 발생

### 20. [chapter06] 컬렉션을 활용한 게임 데이터 관리
다음 두 기능을 모두 포함하는 프로그램을 작성하시오.

조건:
- `List<String>` 또는 `List<GameCharacter>`를 사용해 파티 목록을 저장할 것
- `Map<String, Integer>` 또는 `Map<String, ItemSpec>`을 사용해 아이템 정보를 저장할 것
- 파티 목록에서 1명 추가, 1명 삭제를 수행할 것
- 아이템 맵에서 특정 키로 값을 조회할 것
- 마지막에 전체 데이터 상태를 출력할 것

확인 포인트:
- 리스트는 순서 기반 관리
- 맵은 키 기반 조회
